# Codex 介绍

Codex 是 OpenAI 的 AI 编程助手。它不仅能回答代码问题，还可以在获得授权后直接读取仓库、编辑文件、运行命令、检查结果，并协助完成 GitHub 工作流。

## Codex 可以做什么

- 理解现有项目的结构、配置和运行方式
- 新建或修改代码、文档、脚本与自动化工作流
- 安装依赖并运行测试，定位错误后继续修复
- 搜索技术资料，并把方案落到当前仓库中
- 协助提交代码、配置 GitHub Actions 和发布站点

## 它如何工作

Codex 通常会先检查仓库和任务目标，再进行最小范围的修改。修改完成后，它会运行与风险相匹配的验证，例如语法检查、配置加载、测试或真实工作流，并明确说明哪些部分已经完成、哪些仍需人工授权。

## 安全边界

Codex 不应把 API 密钥写入公开代码。此项目把 DeepSeek 密钥保存在本机忽略的 `.env` 文件和 GitHub 加密 Secret 中。涉及登录、授权、公开发布或其他重要外部操作时，Codex会在需要的位置取得用户确认。

## 在本项目中的作用

本仓库由 Codex 协助完成了日本留学信息源配置、中文筛选提示词、DeepSeek 接入、每日 GitHub Actions、GitHub Pages 发布和运行验证。日常更新由自动化完成，也可以在 Windows 中双击 `启动日本留学新闻雷达.cmd` 手动运行。

更多产品信息可查看 [OpenAI Codex](https://openai.com/codex/)。
